### Design Decisions
1. **`AbstractActionBean`** is assigned to all 3 microservices as a shared base class — it provides the Stripes ActionBean framework infrastructure and is a compile-time dependency inherited by all action beans. Each microservice will include its own copy.
2. **No unassigned classes remain** — all 26 class instances are accounted for across the 3 domains.
3. **Cross-domain dependencies** (e.g., `CatalogService` used in `AccountActionBean` for favorite category display, `ItemMapper` used in `OrderService` for inventory updates) represent future **inter-service API calls** in the microservice architecture.
4. **Clear bounded contexts** ensure each microservice owns its data and can be deployed, scaled, and maintained independently.
